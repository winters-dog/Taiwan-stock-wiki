# K線圖入門

## 1. 基本概念

K線（Candlestick Chart，又稱蠟燭圖或陰陽線）是金融市場中最廣泛使用的價格記錄圖表。起源於日本江戶時代的米市交易，後來被廣泛應用於全球股票、期貨與外匯市場。

每一根K線都記錄了某個特定時間區間內（例如一分鐘、一天、一週或一個月），價格波動的四個關鍵數據：
* **開盤價（Open）**：該時間區間開始時的第一筆成交價。
* **最高價（High）**：該時間區間內曾觸及的最高成交價。
* **最低價（Low）**：該時間區間內曾觸及的最低成交價。
* **收盤價（Close）**：該時間區間結束時的最後一筆成交價。

## 2. 原理與運作方式

### K線的構造解剖
K線由兩個核心部分組成：
```
        最高價 (High)
           │     ▲
       ┌───┴───┐ │ 上影線 (Upper Shadow)
       │       │ ▼
       │ 實體  │
       │(Body) │
       └───┬───┘ ▲
           │     │ 下影線 (Lower Shadow)
           │     ▼
        最低價 (Low)
```

1. **實體（Real Body）**：
   * 指「開盤價」與「收盤價」之間的矩形長塊區域。
   * 實體的高度反映了該時段內開盤與收盤之間價格位移的幅度大小。
2. **上影線（Upper Shadow）**：
   * 實體頂部向上延伸到最高價的細線段。
   * 代表買方曾一度將價格推升至該高點，但隨後遭遇賣壓回落的痕跡。
3. **下影線（Lower Shadow）**：
   * 實體底部向下延伸到最低價的細線段。
   * 代表賣方曾一度將價格打壓至該低點，但隨後受到買盤支撐回升的痕跡。

### 顏色與台股慣例（重大觀念澄清）
* **台股市場習慣**：
  * **紅K線（陽線）**：收盤價 **高於** 開盤價（收盤 > 開盤）。實體通常塗滿紅色。
  * **綠K線（陰線）**：收盤價 **低於** 開盤價（收盤 < 開盤）。實體通常塗滿綠色。
* **重要觀念澄清**：
  * **紅K不等於上漲**：紅K僅代表當天「收盤價高於開盤價」，如果當天開盤是跳空大跌後小幅反彈，收盤價仍可能低於「前一交易日的收盤價」（即大盤或個股報價依然顯示下跌）。
  * **綠K不等於下跌**：綠K僅代表當天「收盤價低於開盤價」，如果當天開盤是跳空大漲後拉回，收盤價仍可能高於「前一交易日的收盤價」。
  * 國際市場慣例（如美股）多以綠色代表上漲、紅色代表下跌，初學者在閱讀不同看盤軟體時，必須先確認軟體的色彩設定。

## 3. 核心重點

### 常見K線外觀與形態解讀
K線的外觀會因多空雙方的拉鋸力量而呈現多樣變化：
* **長實體紅K**：開盤後買盤強勁，收盤大幅拉升，顯示該時段買方力量明顯占優勢。
* **長實體綠K**：開盤後賣壓沉重，價格一路下探，顯示該時段賣方力量強烈主導。
* **長上影線**：盤中多方曾發動攻勢創高，但高檔賣壓湧現，收盤被壓回，代表上方存在明顯阻力（壓力）。
* **長下影線**：盤中空方一度大幅殺跌，但低檔有買盤逢低承接，收盤強勁反彈，代表下方存在一定支撐。
* **短實體與十字線（Doji）**：開盤價與收盤價幾乎相同，上下影線長度接近，顯示多空雙方力量處於均衡拉鋸，市場觀望氣氛濃厚。

### 時間週期（Timeframes）
依據記錄的時間尺度不同，K線可分為：
* **日K線**：記錄單一完整交易日（09:00~13:30）的四價，為波段與中短期觀察最常用的基準。
* **週K線 / 月K線**：由整週或整月的價格數據彙整而成，適合過濾短期每日波動雜訊，觀察中長期走勢趨勢。
* **分K線（如 5分K、60分K）**：將單日切細為多個時段，主要用於短線交易或當日走勢的精細觀察。

## 4. 實際應用

1. **搭配成交量綜合判讀**：單獨一根長紅K線不足以證明買氣可持續，若同時伴隨「成交量放大」，則代表多方參與度高；若成交量萎縮，可能是少量買盤推升的冷門現象。
2. **觀察相對位置**：同一種K線形態（如長下影線）出現在股價經過長期大跌之後，與出現在歷史天價高檔區，其市場心理與涵義截然不同。
3. **長短期週期互補**：初學者應「先看大趨勢（週K/月K），再看小細節（日K）」，切忌只盯著極短線分K，容易被短線雜訊干擾決策。

## 5. 優點與限制

### K線的優點
* **直觀且資訊密度高**：一根簡單的線條就能同時展現開、高、低、收四個價格，並反映當期的多空勝負。
* **真實反映群眾心理**：上下影線直觀呈現多空交戰過程中的妥協與抗衡痕跡。

### K線的限制（必讀警示）
* **僅記錄已發生的歷史事實**：K線僅代表「過去」的交易紀錄，**絕對無法保證未來的價格走勢**。
* **無法解釋價格變動的根本原因**：K線無法單獨告訴投資人為什麼股價上漲（是因為公司接獲大單，還是特定資金短期炒作）。
* **容易受到主力資金刻意作價影響**：特別是在小型股、成交量稀少的中小型冷門股上，少數大資金可能透過尾盤撮合刻意畫出特定K線圖形，誤導技術分析者。

## 6. 常見問題

### Q1：看到長紅K線就可以立刻買進嗎？
**不可以。** 長紅K線只代表在剛過去的這個時段內買盤強勢，但隔天可能面臨獲利了結賣壓或總體經濟利空而拉回。投資決策必須綜合評估成交量、趨勢位置、公司基本面營運以及大盤整體環境。

### Q2：為什麼看美股軟體時，綠色反而是上漲？
這是不同金融市場的文化習慣。台灣市場沿襲華人文化以「紅色」代表吉祥、繁榮（漲），以「綠色」代表跌；而西方歐美市場以「綠色（Green）」代表獲利與通行（漲），以「紅色（Red）」代表虧損與赤字（跌）。使用軟體時應先確認其顏色定義。
